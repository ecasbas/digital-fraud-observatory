# Contributing

The simplest contribution is one public report URL and a short lesson explaining what readers should notice or verify. A researcher, vendor, regulator, news organization or other attributable source can supply evidence; no particular provider is required.

Choose one route:

1. Open [New example](https://github.com/ecasbas/digital-fraud-observatory/issues/new?template=new-example.yml) and complete the short form.
2. Use the contribution page on the website to prepare an email or GitHub draft.
3. For a correction, open [Correction](https://github.com/ecasbas/digital-fraud-observatory/issues/new?template=correction.yml), include the case ID and a supporting source.

Optional source and contributor names determine credit. Disclose any connection to the subject or vendor.

Do not submit personal victim data, credentials, private conversations or executable payloads. Link to public research instead of a live fraudulent site. Screenshots need source attribution and a lawful basis for redistribution; do not grant rights you do not hold.

Separate visible facts, the source's assessment and your interpretation. Describe limits. AI generation needs supporting evidence; polished design alone does not establish it. Label reconstructions clearly. AI-assisted contributions are welcome when you verify every source.

Maintainers check provenance, supporting evidence, duplication, privacy and rights before publishing. Publication is not automatic. No vendor receives a preferred evidence standard. A maintainer may ask for clarification, request a safer redaction, or close a submission that cannot be verified. Corrections should update the explanation and checked date together, recording material changes in the pull request. Withdrawals should explain why the case was withdrawn.

For code or metadata changes, build and run the static checks described in README.md. Code contributions are offered under MIT; original editorial text under CC BY 4.0. Third-party material keeps its own rights. Only contribute material you may lawfully share.
