# Contributing

The easiest contribution is a public report URL and one or two sentences explaining what readers should notice or verify.

1. Open [New example](https://github.com/ecasbas/digital-fraud-observatory/issues/new?template=new-example.yml).
2. Paste the report link and write the lesson.
3. Submit the issue. A maintainer reviews it before publication.

To correct an existing case, use [Correction](https://github.com/ecasbas/digital-fraud-observatory/issues/new?template=correction.yml) and include the case ID plus supporting evidence. Translations, counterexamples and improvements to the site are welcome.

Do not submit personal victim data, credentials, private conversations or live malicious links. Use public sources and only share screenshots or text you may lawfully redistribute.
